# Loulou OS

Live demo: <https://mohamedbsila.github.io/alle/>

Open `Loulou_OS_Doodle_Duel_Fixed.html` in a browser to run the app locally. GitHub Pages publishes this file as the site homepage.

Some features load libraries, images, or models from external CDNs and services, so they require an internet connection. Camera features also require browser camera permission.
